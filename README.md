A StableBaselines3 environment used to train 

### Getting started (Windows)

1. Create a venv with 
```
python3 -m venv .venv
```
2. Activate it with 
```
.venv\Scripts\activate
```
3. Tell the shell where Vivado is (this is an example path, please change accordingly)
```
$env:PATH += ";F:\Vivado\2022.1\bin"
```
4. Run with 
```
python3 .\training\train_xsim.py --data_dir sample_data_9_lanes --sim_dir C:\Users\macth\Documents\T8_Decomp_xsim\sim
```

### Run inference on one prepared image (Windows)

The XSim environment takes a prepared sample, not a PNG/JPEG directly. The sample folder must
contain `beats_hex` and `rows_hex` subfolders generated by the image-to-hex preprocessing flow.
Run a trained MaskablePPO checkpoint with:

```
python .\deployment\infer_xsim.py --model .\models\ppo_hw_checkpoint.zip --image-dir .\sample_data_9_lanes\test_11_lantern --sim-dir C:\path\to\T8_Decomp_xsim\sim --output .\generated_beats.hex
```

`--image-dir` can also point directly to the sample's `beats_hex` folder. The output contains one
raw `action_hex` value per line, without the separate valid flag or any prefix, including hex
values for no-op cycles. It is the dispatched beat stream, not the source per-lane hex files.
Use `--obs-version` if the checkpoint was trained with an observation version other than `v3`.

### Getting started (Linux)

1. Create a venv with
```
python3 -m venv .venv
```
2. Activate it with
```
source .venv/bin/activate
```
3. Tell the shell where Vivado is (change this to your actual install path)
```
export PATH="$PATH:/opt/Xilinx/Vivado/2022.1/bin"
```
4. Run with
```
python3 ./training/train_xsim.py --data_dir ./sample_data_9_lanes --sim_dir /home/{PATH_TO_TB}/T8_Decomp_xsim/sim
```
